# 🟢 Nivel Básico

Ejercicios para entender los fundamentos de Terraform.

## Ejercicios

| # | Ejercicio | Descripción |
|---|-----------|-------------|
| 01 | [First Resources](./01-first-resources/) | Tu primer recurso: instancia EC2 |
| 02 | [Variables & Outputs](./02-variables-outputs/) | Reutilización con variables y outputs |
| 03 | [Data Sources](./03-data-sources/) | Consulta información existente |

## Lo que aprenderás

- Estructura básica de archivos .tf
- Provider configuration
- Recursos (resource blocks)
- Variables de entrada
- Outputs
- Data Sources

## Tiempo estimado
1-2 horas por ejercicio

## Requisitos
- Terraform >= 1.6
- AWS CLI configurado o cuenta en cloud provider
