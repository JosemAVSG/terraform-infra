# 🟡 Nivel Intermedio

Ejercicios para profundizar y crear código más robusto y reutilizable.

## Ejercicios

| # | Ejercicio | Descripción |
|---|-----------|-------------|
| 04 | [Modules](./04-modules/) | Crea módulos reutilizables |
| 05 | [Conditionals & Loops](./05-conditionals-loops/) | Recursos dinámicos |
| 06 | [Remote State](./06-remote-state/) | Backend y state management |

## Lo que aprenderás

- Módulos propios (child modules)
- Expresiones avanzadas (for_each, count, conditionals)
- Terraform functions (lookup, coalesce, etc.)
- Remote backends (S3, GCS)
- State locking (DynamoDB)
- Workspaces basics

## Tiempo estimado
2-3 horas por ejercicio

## Requisitos
- Completar nivel básico
- Familiaridad con servicios de AWS/GCP/Azure
